# 🏠 主网页设计方案 —— AI 校园生活 · 沉浸式落地页

> **模块**：主网页（总入口）
> **定位**：整个产品的门面与导航中心，纯前端静态页面
> **边界**：❌ 不负责各模块的服务端合并与部署衔接（由后续 Agent 完成），✅ 只交付主网页前端 + 清晰的入口衔接点
> **技术栈**：HTML5 + CSS3 + JavaScript(ES6)，零框架、零 CDN、零外部素材依赖

---

## 一、产品定位

- 单页沉浸式落地页：打开即见全屏 Hero，向下滚动依次浏览四大模块板块
- 面向两类读者：**评委**（30 秒看懂产品是什么）与**用户**（一键直达各功能模块）
- 视觉基调：**精致治愈的校园风**——与模拟器"录取通知书 + 方格作业本"的气质统一，同时兼容情绪地图/日记帮写的柔和渐变风

---

## 二、产品名称与标语（✅ 已定稿）

# **CampusVerse · 双界校园**

> 标语：**虚拟与真实，都是你的校园**

### 命名释义

"双界"对应产品的**双分支结构**：

| 分支 | 包含模块 | 用户心智 |
|------|----------|----------|
| 🌌 **平行界 · 预演未来** | 大学模拟器 | "我还没上大学 / 想重来一遍"——AI 生成的平行四年 |
| 🏫 **现实界 · 校园进行时** | 情绪地图、课表排雷、日记帮写 | "我已经上大学了，要解决真实问题"——日常工具 |

- 英文品牌 **CampusVerse** 用作 Hero 双语标题的英文行与 LOGO 字样
- Demo 叙事一句话："每个大学生都该有两所大学——一所用来预演，一所认真去活。"

> 页面代码中名称集中定义在 `js/config.js` 的 `SITE_TITLE` / `SITE_SLOGAN`，一处修改全站生效。

## 四、视觉设计规范

### 4.1 CSS 变量（沿用预设框架统一变量，主网页自带一份不依赖各组 common/）

```css
:root {
  --primary-color: #4A90D9;      /* 主色调 - 校园蓝 */
  --primary-light: #6BA5E7;
  --primary-dark: #3A7BC8;
  --bg-body: #F7F9FC;
  --card-bg: #FFFFFF;
  --text-main: #2D3748;
  --text-sub: #718096;
  --border: #E5E7EB;
  --radius-card: 16px;
  --radius-btn: 8px;
  --shadow-elevation: 0 10px 20px rgba(0,0,0,0.05);
  --shadow-lg: 0 20px 40px rgba(0,0,0,0.1);
  --font-family: 'PingFang SC', 'Microsoft YaHei', -apple-system, sans-serif;
  --font-serif: 'SimSun', 'Noto Serif SC', serif;   /* Hero 标题，呼应录取通知书 */
  --transition: all 0.3s ease;
}
```

### 4.2 视觉实现原则

- **全部图形用 CSS 渐变 + 内联 SVG**：光斑（radial-gradient blur）、方格作业本纹理（repeating linear-gradient）、模块插画区（各识别色渐变 + emoji/大图标），杜绝图片加载失败
- Hero 标题采用**双语锁定**排版：英文行 `CampusVerse`（无衬线加粗 + 字距拉宽，科技感）→ 中文行「双界校园」（衬线大字，呼应录取通知书）→ 标语行小字灰
- 可选加**打字机逐字效果**（与模拟器首页呼应，纯 JS ~20 行，待确认）
- 两个分区各有分区头：平行界用深蓝星空渐变底 + 星点 SVG；现实界用校园蓝日间渐变底
- 每个模块卡片顶部一条识别色渐变色带作为"氛围签名"

### 4.3 动效规范

| 动效 | 实现 | 参数 |
|------|------|------|
| 滚动渐入 | IntersectionObserver | 位移 60px，0.6s ease-out，触发一次 |
| 卡片 hover | CSS transform | 上浮 -8px + 阴影升级 |
| 光斑漂移 | CSS keyframes | 12s 无限缓动 |
| 无障碍 | `prefers-reduced-motion` | 命中时全部动画关闭 |

## 五、交互设计

1. **顶部锚点导航**：平滑滚动（`scroll-behavior: smooth`），滚动超过 Hero 后导航栏加白色底 + 阴影
2. **模块进入按钮**：统一 `data-module="simulator|emotion|schedule|diary"` 属性，点击时读入口配置：
   - 已配置真实地址 → 正常跳转
   - 未配置（空串或 `#`）→ toast 提示「该模块正在接入中，敬请期待～」，**绝不死链**
3. **CTA「开始探索」**：滚动至模块区第一板块

## 六、模块衔接规范（⚠️ 交给后续 Agent 的关键约定）

所有模块入口集中在 `js/config.js`，后续 Agent **只需改这一个文件**即可完成接入：

```javascript
/** 站点信息 */
const SITE_TITLE  = 'CampusVerse · 双界校园';
const SITE_SLOGAN = '虚拟与真实，都是你的校园';

/** 四大模块入口配置（占位值 = 各组当前已知访问路径） */
const MODULE_ENTRY = {
  simulator: '/simulator/',          // 模拟器组 main/server.js
  emotion:   '/tools/emotion/',      // 模块A · 情绪地图
  schedule:  '/tools/schedule/',     // 模块B · 课表排雷（占位，合并时定）
  diary:     '/tools/diary/',        // 模块C · 日记帮写（占位，合并时定）
};

/** 跳转方式：'_self' 当前页跳转；如需 iframe 内嵌由后续 Agent 改此约定 */
const MODULE_TARGET = '_self';
```

**已知现状提醒**（来自探查，供合并 Agent 参考）：
- 四个模块当前 server.js 默认端口**全部是 3000**，无法同时启动，合并时须统一为一个服务或错开端口
- 模块B 和模块C 的页面路径都是 `/tools/`，合并时**必须重命名区分**（config 中的 schedule/diary 占位路径即为此预留）
- 各模块根路径 `/` 目前都有 redirect，合并后可将 `/` 让给本主网页作为全站首页
