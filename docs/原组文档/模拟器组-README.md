# 🎮 AI 大学生活模拟器

AI 驱动的大学人生模拟游戏：扮演一名大学新生，经历 8 个学期、48 个关键节点的决策，四年后获得由 AI 生成的性格画像（MBTI 实测 vs 开局自评对比）、四维能力雷达图与毕业去向。

## 快速开始

```bash
# 1. 进入工程目录
cd main

# 2. 安装依赖（需要 Node.js v18+）
npm install

# 3. 配置 API Key（复制模板后填入）
#    .env 文件内容：
#    MIMO_API_KEY=你的小米 MiMo 密钥
#    PORT=3000
copy .env.example .env   # Windows

# 4. 启动
npm start
```

浏览器打开 <http://localhost:3000/simulator/>

## 目录结构

```
main/
├── server.js              # 后端：AI 代理（隐藏 API Key）+ 静态服务
├── common/                # 公共资源（CSS 变量/组件、存储与 AI 调用封装）
└── simulator/             # 模块 A · 大学模拟器
    ├── index.html
    ├── css/sim-style.css
    ├── js/game-engine.js  # 游戏引擎（数值/时钟/预加载/存档）
    ├── js/ai-service.js   # 8 类 AI 提示词 + 兜底事件池
    ├── js/app.js          # 界面流转与渲染
    └── assets/images/     # 场景图（放入 campus/classroom/... .png 即自动生效）
```

## 已实现功能

- ✅ 角色创建（姓名/性别/学校/专业/自评 MBTI）+ AI 开学开场白
- ✅ 48 事件循环（每学期 6 个）+ AI 实时生成 + 后台预加载
- ✅ 3 预制选项（隐藏数值，选择后才反馈）+ 1 自定义输入（宽松判定：仅拦截违法有害与超现实行为，其余一律放行；收益单项封顶 10、正向总和封顶 18 防刷分）
- ✅ 四维属性系统（精力/学业/人际/心态 + 子项目，数值强制钳制）
- ✅ 事件类别按配额分配（48 个 = 学业 6 / 实践 7 / 宿舍 8 / 运动 9 / 社交 9 / 娱乐 9），由系统指定而非 AI 自选，避免学业类挤占生活类；同类事件不连续出现
- ✅ 危机/巅峰事件倾向（属性 <10 / >95 时引导 AI）
- ✅ 学期总结（关键选择回顾 + 属性变化对比 + 雷达图 + AI 评语）
- ✅ 毕业报告（MBTI 实测 vs 自评对比、雷达图、毕业去向、成就徽章、四年时间线、结语）
- ✅ 危机/巅峰事件（任一属性 <10 强制触发危机，学业/人际/心态 >95 触发巅峰；专属提示词 + 本地兜底池 + 同学期冷却）
- ✅ 属性权重平衡（对称软边界，避免精力提前见底 / 其他三维过早封顶）
- ✅ 取舍原则 + 属性压力反馈（`statPressureHint()`）：事件必须提供有代价的选项，属性 ≥70 强制给下滑选项、≤30 强制给回升选项，避免心态/人际只涨不跌
- ✅ 存档/读档/自动保存（LocalStorage，含版本兼容与字段兜底）
- ✅ 重新开始 / 再来一次：完整重置（清对局、待播事件、表单、MBTI），确认用页面内弹窗（不依赖浏览器原生 `confirm`，避免被拦截后按钮失效）
- ✅ 图片缺失时 CSS 渐变 + 场景 emoji 兜底
- ✅ AI 文案打字机效果（开场白 / 事件场景 / 选择反馈 / 学期总结 / 毕业结语，点击文本可跳过）
- ✅ MBTI 自评四维大框（I/E · N/S · T/F · J/P 各选一个，带大白话提示，自动拼出 16 型）
- ✅ 16:10 视口适配：场景背景出血撑满窗口宽度、高度随视口缩放；长文本中文断行 + 两端对齐排版

## 开发者工具

所有调试脚本位于 `tools/scripts/` 目录：

```bash
# 事件类别配额验证：检查分布均衡性、无连续重复、旧存档兼容
cd tools/scripts
node dev-category-test.js

# 毕业去向判定 + 矛盾词检测：验证规则判定和文案一致性
node dev-destination-test.js

# 自定义行动宽松判定测试：验证黑名单拦截是否生效
node dev-custom-judge-test.js    # 需启动服务器

# 自定义行动单元测试：本地硬编码校验（不需要服务器）
node dev-custom-unit-test.js

# 属性权重调参与蒙特卡洛模拟：评估不同玩法的终值分布
node dev-balance-test.js         # 需启动服务器

# 状态变化探针：诊断 AI 生成事件的 effects 分布（特别是心态/人际是否只涨不跌）
node dev-effects-probe.js        # 需启动服务器

# 属性平衡深度测试：用真实事件池做 300 局蒙特卡洛
node dev-stat-balance-test.js    # 需启动服务器

# CDP 自动化浏览器测试：实测重新开始按钮在 confirm 被拦截时是否正常
node dev-browser-restart-test.js # 仅本机 Edge 环境运行
```

**注意**：需要调用 AI 接口的脚本必须先启动服务器（`npm start`），本地单元校验类脚本无需服务器。
