## 1. 产品概述

### 1.1 产品定位

**CampusVerse · 双界校园**是一个面向大学生的四合一 AI 校园应用平台，通过「预演大学」与「真实校园」两大维度，帮助学生更好地理解大学生活、规划学习路径、管理情绪状态。

> "每个大学生都该有两所大学——一所用来预演，一所认真去活。"

### 1.2 核心愿景

- **左侧：平行界（模拟）** → 通过模拟器体验不同的选择与可能
- **右侧：现实界（工具）** → 提供实用的校园效率工具

### 1.3 目标用户

| 用户群体      | 痛点              | 解决方案          |
| --------- | --------------- | ------------- |
| **大一新生**  | 对大学生活迷茫，不知道如何选择 | 模拟器提供多种人生路径体验 |
| **大二学生**  | 选课困难，担心踩雷       | 课表排雷分析课程风险    |
| **情绪困扰者** | 压力无处宣泄，缺乏自我觉察   | 情绪地图可视化内心状态   |
| **写作困难户** | 周记/日记无从下笔       | AI 日记帮写快速成文   |

## 5. 部署运维

### 5.1 本地开发环境

#### 前置条件

- **Node.js 18 或更高版本**（服务端用到原生 `fetch` 和流式响应，低版本跑不起来）
- 现代浏览器（Chrome / Edge / Firefox）
- 一个可用的 **MiMo API Key**（AI 功能必需，没有它四个模块的 AI 都会提示「未配置密钥」）

> 检查 Node 版本：终端运行 `node -v`，确认 ≥ 18。

#### 第一步：配置 `.env`（环境变量）

项目根目录已经放了一个模板文件 `.env.example`，里面是空 Key。你只需要复制一份、改掉 Key：

**1. 复制模板生成 `.env`**

```bash
# Windows（PowerShell）
Copy-Item .env.example .env

# macOS / Linux
cp .env.example .env
```

**2. 用文本编辑器打开 `.env`，填入你自己的 Key**

```ini
# 小米 MiMo 大模型 API Key（四个模块的 AI 能力都走它）
MIMO_API_KEY=sk-在这里填你的密钥

# 上游地址与模型（换供应商时改这两行即可）
AI_BASE_URL=https://api.xiaomimimo.com/v1
AI_MODEL=mimo-v2.5

# 全站统一端口（原来四个模块都想占 3000，只能开一个）
PORT=3000
```

**3. 各变量说明**

| 变量名 | 必填 | 默认值 | 作用 |
| ------ | ---- | ------ | ---- |
| `MIMO_API_KEY` | ✅ | 无 | MiMo 大模型的 API Key，**AI 功能的核心**，不填则四个模块的 AI 全部不可用 |
| `PORT` | ❌ | `3000` | 服务监听端口，被占用时改这里，比如 `PORT=8080` |
| `AI_BASE_URL` | ❌ | `https://api.xiaomimimo.com/v1` | AI 上游地址，换供应商时改这一行 |
| `AI_MODEL` | ❌ | `mimo-v2.5` | 使用的模型版本 |

> ⚠️ **重要**：`.env` 里是真实密钥，**已经被 `.gitignore` 忽略，绝不会提交到仓库**。改完 `.env` 后**必须重启服务器**才会生效。

#### 第二步：启动服务器

```bash
# 进入项目根目录（就是有 server.js 的这一层）
cd campusverse

# 直接运行（零依赖，不需要 npm install）
node server.js
```

启动成功后，终端会打印全部入口地址，包括局域网地址。

#### 第三步：浏览器打开

- 本地：http://localhost:3000/
- 局域网（同一 WiFi 的手机也能访问）：http://<你的IP>:3000/

#### 常见问题

| 现象 | 原因与解决 |
| ---- | ---------- |
| AI 功能提示「服务端未配置 MIMO_API_KEY」 | `.env` 没填 Key，或填错；改完要**重启服务** |
| 端口被占用 `EADDRINUSE` | 改 `.env` 里的 `PORT=8080`，或临时 `set PORT=8080 && node server.js`（Windows）/ `PORT=8080 node server.js`（macOS/Linux） |
| 页面能开但 AI 一直转圈 | 先跑 `node tests/smoke-test.js --ai` 真调一次 AI，看具体报错 |

- 拒绝暴露后端源码 (`server.js`)

| 路径              | 权限            |
| --------------- | ------------- |
| `/`             | 公开            |

| `/modules/*`    | 公开            |
| `server.js`     | 403 Forbidden |
| `.env`          | 403 Forbidden |

- Body 大小上限：30MB（防止大文件攻击）
